# Подготовка Fixly к независимому тестированию

Дата: 2026-09-24.

- HANDOFF-001: архив содержит актуальные web/, app/, спеки, lock-файлы, безопасные примеры окружения и инструкцию. Секреты, дампы БД, реальные загрузки, история Git и кэши исключаются; состав проверяется автоматически.
- HANDOFF-002: локальный запуск тестера создаёт отдельный Compose-проект и новую БД из миграций, задаёт пароли ролей, создаёт только синтетические демо-данные. Скрипт не перезаписывает имеющийся .env и не удаляет тома.
- HANDOFF-003: service worker кэширует только явную статику приложения. API, страницы с сессией и загруженные файлы идут по сети; устаревшие runtime-кэши предыдущей версии очищаются при активации.
- HANDOFF-004: импорт выписки доступен только председателю через tenant-транзакцию. Сервер проверяет формат, сумму, дату и принадлежность лицевого/банковского счёта; повторный импорт не создаёт дубликаты. Сопоставление по номеру квартиры требует дома, неоднозначное сопоставление требует ручного выбора.
- HANDOFF-005: ошибки проверки входа и прав возвращаются как HTTP-ответы; ошибки внутренних сервисов не раскрываются пользователю.
- HANDOFF-006: статические замечания исправляются без отключения правил. В инструкции указываются фактические результаты проверок и оставшиеся ограничения; готовность не приравнивается к успешной сборке.
- HANDOFF-007: мобильный клиент может запускаться без Firebase при ENABLE_PUSH=false; конфигурация владельца заменяется в архиве явной заглушкой, `.env.example` отключает push.

Проверка: unit/integration для изоляции и идемпотентности импорта, typecheck, сборка, проверка состава ZIP и развёртывание тестовой БД. APK проверяется при доступном Android SDK; отсутствие сборки фиксируется явно.
