# Госинтеграции и регуляторный контур (блок E + голосования блок C)

> Статус: DRAFT · Версия: 0.2 · Дата: 2026-07-01
> Обновлено после получения текста действующего приказа № 163 (V2000020283, ред. № 380 от
> 22.09.2025) и правового разбора доступа к госбазам. Это **самый твёрдый блокер проекта**
> (Q-039): не код, а регуляторика + партнёрство. Требует подтверждения у оператора Smart Bridge
> и профильного юриста — но контур уже ясен.

## 0. 🔴 ГЛАВНОЕ: барьер «объект информатизации в сфере ЖКХ»

Из текста закона (Приложение 1 к № 163, пп. 3, 22, 23) и правового разбора:

**Легитимные электронные голосования собственников и доступ к госбазам возможны ТОЛЬКО через
аккредитованный «объект информатизации в сфере жилищных отношений и ЖКХ»** — специальный статус
ИС, интегрированной с ГИС Министерства промышленности и строительства. Функционирование таких
объектов регулируется отдельным приказом **№ 172 от 31.03.2020 (V2000020245)** — это документ
№1 к прочтению.

**Решено (ADR-0007):** из двух моделей для соло-разработчика жизнеспособна только B.

| Модель | Что нужно | Вердикт |
|---|---|---|
| **A. Аккредитоваться самим** | Аттестация ГТС (ст. 49 Закона «Об информатизации»): выделенный CISO + сисадмины + служба ТП (СТ РК ИСО/МЭК 27001), 30+ регламентов ИБ, ЦОД **Tier III в РК** + СЗИ/WAF + подключение к **ЕШДИ** и **SOC**. Стоимость ~$15–20k (аудит 1,5–3 млн ₸ + пошлина ГТС 2–5 млн ₸ + хостинг от 300к ₸/мес). Срок 6–12 мес. | 🔴 **ЗАКРЫТА для соло** — экономически/организационно недостижима без инвестиций и команды. |
| **B. API-медиатор / white-label** | Договор с аккредитованным партнёром; мы — **обработчик ПДн по поручению**. Наше приложение = UX-фронтенд; запросы к госданным/голосованиям идут через API партнёра (у него ГТС пройден). Плата ~5 ₸/запрос. | ✅ **ВЫБРАНА** (ADR-0007). Экономит ~$15–20k и год; но зависимость от партнёра — управлять договором. |

⚠️ Управдом/e-Shanyraq — аккредитованные объекты и потенциальные партнёры-провайдеры API, но они
же конкуренты. **Предпочтителен нейтральный аккредитованный оператор** (финтех/идентити, не прямой
ЖКХ-конкурент) — выбор партнёра открыт (Q-043). Риски и митигации зависимости — ADR-0007.

Ограничение аккредитации касается только блока C (легитимные голосования) и блока E (госданные).
**Фазы 1–2 (коммуникация + учёт/автоотчёт из выписки Kaspi) аккредитации НЕ требуют** и строятся
независимо (Тир 1). См. §5.

## 1. Экономика Smart Bridge (изменилось — теперь платно)

- **ЭЦП организации** (`pki.gov.kz`, НУЦ РК) — **бесплатно** для всех.
- **Smart Bridge (`sb.egov.kz`)** — ранее бесплатно, теперь **возмездная модель** (Приказ
  № 104/НҚ). Платформы ЖКХ заключают платный э-договор в ЛК Smart Bridge; тариф зависит от
  объёма транзакций к ГБД ФЛ / Регистру недвижимости (оператор — АО «НИТ»).
- **Песочница (Sandbox / тестовый контур) — бесплатно:**
  - Тестовые ЭЦП (физ/юр) скачиваются бесплатно на `pki.gov.kz` («Разработчикам»).
  - Тестовые ГБД ФЛ/Регистр недвижимости — демо-данные («Иванов Иван Иванович»); реальные ИИН
    запрещены.
  - Доступ: регистрация на `smartbridge.gov.kz` → выбрать API → «Подключиться к тестовому
    контуру» → **авто-одобрение за 1–2 дня** → тестовые токены + эндпоинты `test-api.egov.kz`.
  - Прод: отдельная заявка + протокол тестирования → модерация 5–15 дней → договор с АО «НИТ» + тариф.
- 💡 **Экономический смысл платформ:** ОСИ сами не платят за госзапросы — аккредитованная
  платформа берёт тарифы Smart Bridge на себя и закладывает их в абонплату (~15–30 тг/квартира
  в мес.). Это и есть бизнес-модель Управдома. Наша подписка должна покрывать эти транзакционные
  издержки.

## 3. Правовой контур (обязательно до реализации блоков C/E)

- **Основание обработки без согласия:** ст. 42-1 Закона «О жилищных отношениях» (обязанности
  ОСИ: собрания, опросы, расчёт долей) + ст. 9 Закона «О ПДн» (обработка в рамках законодательных
  актов). Т.е. базовую обработку ИИН/данных ОСИ вести вправе — но с обязанностями оператора.
- **Статус оператора ПДн:** ОСИ/ПТ — операторы баз ПДн. Обязаны:
  1) уведомить **Комитет по информационной безопасности МЦРИАП** о начале обработки (госреестр операторов);
  2) утвердить внутренний **Регламент сбора и защиты ПДн**;
  3) назначить приказом **ответственное лицо** (председатель/бухгалтер);
  4) хранить данные (в т.ч. Excel с ИИН) только на инфраструктуре **в РК** (уже покрыто ADR-0003/NFR-051).
- **Биометрия — жёстко:** изображение лица = ПДн **особой категории (ограниченного доступа)**.
  - Только по **явному письменному согласию отдельным обособленным документом** (нельзя прятать
    в оферте/договоре с УК).
  - Обязательна **альтернатива** без биометрии (ключ/карта/PIN) — нельзя принуждать.
  - Хранение — на серверах в РК с подтверждённым уровнем защиты (нац. система биом. аутентификации).
- **Приватность отчёта** — см. report-spec.md §Приватность (что публично, что скрывается).

## 4. Голосования — что говорит закон (Приложение 1 к № 163, для блока C)

- **Кворум:** собрание правомочно при участии **> 50%** от общего числа собственников квартир/
  нежилых помещений.
- **Два порога решений:** часть вопросов — большинством **участвовавших** (п. 11), часть —
  большинством **от общего числа** собственников (п. 12). Замена лифта подъезда за бюджет — **⅔**
  собственников подъезда.
- **Форматы:** явочный, заочный (письменный опрос), электронный — **через объект информатизации
  в сфере ЖКХ**, с обязательной **идентификацией собственника**.
- **Электронный протокол** подписывается **ЭЦП** председателя, секретаря, членов совета дома.
- **Типы решений** (≈20, пп. 11–13): выбор формы/субъекта управления, председатель/совет/ревизор,
  тарифы и сметы, целевые/накопительные взносы, кап.ремонт и расходование сбер.счёта, замена
  лифтов, годовой отчёт, выбор объекта информатизации ЖКХ и др.
- Формы протоколов и листов голосования — Приложение 2 (Формы 1–4, листы 1–7).

## 5. Что можно строить БЕЗ аккредитации (Фазы 1–2) vs с ней (Фаза 3)

| Без аккредитации (строим сразу) | Требует аккредитации/партнёрства |
|---|---|
| Коммуникация (объявления, заявки, инфо, push) | Легитимные э-голосования собственников |
| Быстрые **неформальные** опросы (не юр. значимые) | Проверка собственника через регистр недвижимости |
| Учёт: тарифы, начисления, платежи, задолженность | Идентификация по ГБД ФЛ / БМГ |
| **Импорт выписки Kaspi + автоотчёт по форме** (bank-import.md) | Биометрия (Digital ID) |
| Кабинет жителя, баланс, реквизиты | Подпись протоколов ЭЦП через гос-контур |

→ **Стратегически это делит продукт на два тира** (см. features.md): Тир 1 (Фазы 1–2) даёт
реальную ценность и продаётся **без гос-барьера**; Тир 2 (Фаза 3) — за регуляторной вехой,
которую можно проходить параллельно.

## 6. План по треку (начать в Фазе 1)
1. **Sandbox Smart Bridge** — бесплатно, авто-доступ 1–2 дня; прототип на демо-данных (риск = 0).
2. Прочитать **приказ № 172 (V2000020245)** — условия статуса «объект информатизации в сфере ЖКХ».
3. **Юрист (ЖКХ + ПДн):** аккредитация самому vs партнёрство; уведомление оператора ПДн; режим биометрии.
4. **ЭЦП организации** (бесплатно) — для боевого Smart Bridge и подписания.
5. Решить модель A/B (§0) по результату (2)–(3); оформить **ADR-0007**.
