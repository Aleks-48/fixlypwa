# Спека: Библиотека документов ОСИ (Document Library)

> Статус: ACTIVE · Дата: 2026-07-23 · Реализовано

## 1. Назначение фичи
Единое хранилище нормативных правовых актов (Приказ №163 и др.), годовых/месячных отчётов, протоколов собраний собственников, договоров с сервисными компаниями и технической документации дома.

## 2. Разграничение прав доступа
- **Председатель (`CHAIRMAN`)**:
  - Загрузка документов с указанием категории, названия, описания, URL и флага видимости (`isPublic`).
  - Просмотр всех файлов (публичных и приватных).
  - Удаление документов своего ОСИ.
- **Житель (`RESIDENT`)**:
  - Просмотр и скачивание только **публичных** файлов (`isPublic = true`) по своему дому.

## 3. Доменная модель (`Document`)
Тенантная модель под RLS (`osiId`):
- `category`: `GOV_REGULATION`, `REPORT`, `PROTOCOL`, `CONTRACT`, `TECHNICAL`, `OTHER`
- `title`: String
- `description`: String?
- `fileUrl`: String
- `isPublic`: Boolean (default `true`)

## 4. Маршруты и компоненты
- API: `/api/documents` (GET, POST, DELETE)
- Компоненты UI: `DocumentForm.tsx`, `DocumentList.tsx`
- Интеграция:
  - Панель председателя: `/app/buildings/[buildingId]/info`
  - Кабинет жителя: `/app/info` (вкладка «Полезное»)
