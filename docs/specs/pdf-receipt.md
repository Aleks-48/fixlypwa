# Спецификация: PDF-квитанция коммунальных начислений (PDF Receipt)

> Статус: DRAFT · Версия: 0.1 · Дата: 2026-07-23
> Архитектурное соответствие: docs/specs/domain-model.md (Charge, Account), REQ-024, REQ-030

Модуль «PDF-квитанция» позволяет жителям и председателям просматривать, распечатывать и экспортировать ежемесячную квитанцию начислений по квартире в формате PDF за выбранный расчетный период.

---

## 1. Функциональные требования

1. **Генерация квитанции за период (`REQ-095`):**
   - Формирование наглядного электронного счёта-квитанции для квартиры за текущий или выбранный месяц.
   - Шапка: Наименование ОСИ, БИН, юридический адрес, телефон председателя/аварийной службы, IBAN текущего и сберегательного счетов.
   - Реквизиты жителя: Адрес МЖД, № квартиры, ФИО жителя, площадь (кв.м), номер лицевого счёта (`Account.accountNumber`).

2. **Детализация начислений:**
   - Таблица разметки по бакетам статей (Приказ №163):
     - *Управление и содержание МЖД* (тариф ₸/кв.м × площадь = сумма).
     - *Капитальный ремонт* (тариф ₸/кв.м × площадь = сумма).
     - *Целевые взносы* (фиксированная сумма).
   - Итоги: Сумма начислено за месяц + Входящая задолженность/переплата = **Итого к оплате**.

3. **Печать и экспорт в PDF (`REQ-096`):**
   - Возможность моментальной печати / сохранения в PDF через кнопку **«Скачать квитанцию (PDF)»** на странице платежей `/app/payments`.
   - Готовая печатная верстка (A4 формат) с помощью специализированных `@media print` стилей (работает на всех мобильных браузерах и ПК).

## 2. API Контракты

- **`GET /api/payments/receipt`**
  - **Params:** `period` (YYYY-MM), `apartmentId` (опционально для председателя)
  - **Response (200 OK):**
    ```json

      "osi": {
        "name": "ОСИ «Абай 15»",
        "bin": "123456789012",
    ```

## 3. UX & Компоненты

- **Размещение:**
  - В разделе **«Финансы»** (`/app/payments` для жителя) добавить кнопку **«Квитанция за месяц (PDF)»**.
  - Страница предпросмотра/печати: `/app/payments/receipt`.
- **Печатные стили (`@media print`):**
  - Исключение элементов навигации, сайдбара, кнопок при печати.
  - Сохранение фирменных границ, четкого шрифта и структурированных таблиц на стандартном листе A4.
