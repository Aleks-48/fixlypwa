# CABINET: выбор кабинета при нескольких ролях

Проблема: вход по OTP всегда направлял в `/app`; пользователь с профилем мастера и ролью жителя попадал к жителю даже с кнопки «Кабинет Мастера».

- CABINET-001: общий вход ведёт на серверный выбор кабинета. При наличии профиля мастера и членства в ОСИ доступны оба кабинета. При одном доступном кабинете переход автоматический.
- CABINET-002: вход с явно выбранной ролью мастера ведёт в `/master`, жителя/председателя — в `/app`. Это действует и для уже вошедшего пользователя. Направления фиксированы; роль в URL не выдаёт права.
- CABINET-003: в обоих кабинетах пользователя с несколькими ролями виден переключатель, доступный также на телефоне. Переключение сохраняет сессию, роли и данные; действуют существующие серверные проверки прав.
- CABINET-004: кнопки ролей на главной сохраняют выбранное назначение при входе. Переход не требует отдельной ссылки или повторного ввода кода.
