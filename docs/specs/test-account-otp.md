# TEST-OTP: вход в существующие тестовые аккаунты

Запрос пользователя: сохранить прежние аккаунты с вымышленными номерами и показывать код на форме, чтобы тестировать роли без SMS/Telegram.

- TEST-OTP-001: прямой локальный вход сохраняет показ кода при OTP_DEV_ECHO=1; данные и роли не пересоздаются.
- TEST-OTP-002: для внешнего тестового сайта код допускается только для точного списка подтверждённых пользователем вымышленных номеров (OTP_TEST_PHONES) и до OTP_TEST_ECHO_UNTIL. NODE_ENV=production всегда запрещает показ. Публичный адрес сверяется с NEXT_PUBLIC_APP_URL.
- TEST-OTP-003: для разрешённых номеров код создаётся обычным механизмом OTP, но не отправляется во внешние каналы; сохраняются срок действия, однократность, лимиты и штатная проверка сессии.
- TEST-OTP-004: на форме явно написано, что тестовый код уже показан и сообщения ждать не нужно. Остальные номера сохраняют текущий способ доставки. Включение внешнего режима не меняет пользователей, роли, пароли или Telegram-привязки.

Это явное исключение из TECH-015 только для перечисленных тестовых аккаунтов. По умолчанию список пуст; рабочие номера в него не добавляются.
