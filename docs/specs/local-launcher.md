# Единый локальный запуск Fixly

Дата: 2026-09-25. Один батник поднимает сервер для сайта, установленного мобильного приложения и Telegram.

- START-001: START_FIXLY.bat запускает Docker/PostgreSQL, миграции, ngrok frontend, Next.js и Telegram webhook. Flutter не собирается и не запускается: приложение на телефоне подключается к этому API.
- START-002: существующий том сохраняется; seed/reset/down -v не вызываются. Docker Desktop запускается при необходимости; ожидание Docker до 10 минут, PostgreSQL до 3 минут.
- START-003: перед генерацией Prisma останавливается только Next.js из текущего web/. Чужой процесс на порту 3000 не останавливается; запуск завершается ошибкой.
- START-004: работающий ngrok-туннель переиспользуется только если он ведёт на локальный порт 3000. Фактический HTTPS URL записывается в web/.env и app/.env перед запуском сайта. Это не меняет URL в уже установленной сборке Flutter.
- START-005: после готовности сайта webhook регистрируется с secret_token без очистки очереди. Секреты не выводятся. Отказ любого обязательного этапа не объявляется успехом.
- START-006: фоновые процессы запускаются скрыто, логи сохраняются в .local-run. Файловая блокировка предотвращает два одновременных запуска. Режим показа кодов остаётся ограничен TECH-015.
- START-007: START_TESTER.bat остаётся отдельным сценарием для друга; основной launcher отклоняет tester .env. Отсутствующие SDK не устанавливаются автоматически.

Изменение скрипта не означает проверку полного перезапуска. Сборка и установка Flutter в этот запрос не входят после уточнения пользователя.
