# Fixly: пакет для тестирования, 24 сентября 2026

## Что исправлено после первого отчёта

- Банковский импорт: права председателя, tenant-транзакции, принадлежность счетов, проверка суммы/даты, сериализация повторных запросов и журнал действий. Клиентский флаг дубликата не определяет результат записи.
- Интерфейс импорта действительно принимает файл, требует выбрать дом, сообщает о непроведённых строках. Несопоставленные платежи и расходы остаются для ручного ввода.
- Исправлены UTF-8 заголовки CSV, календарные даты и Excel-даты; отсутствующая дата больше не подменяется сегодняшней.
- Демо-сид создаёт лицевые счета, включая повторный запуск на старом демо. Это исправление выявлено при проверке импорта через HTTP.
- PWA: API, страницы и загрузки идут по сети; runtime-кэш разрешён только для статических ресурсов. Старые кэши с возможными персональными ответами удаляются при активации новой версии. Загрузки исключены из precache.
- Удалены неиспользуемые импорты без отключения ESLint. Измеренное число ошибок снижено с 226 до 121, предупреждений осталось 7.
- Созданы отдельный Compose-проект, установщик и инструкция тестеру. Неподходящий существующий .env вызывает отказ до изменения данных. Наличие старого тестового тома без исходного .env также блокирует создание новой конфигурации.
- Мобильный клиент поддерживает отключение Firebase через ENABLE_PUSH=false. В архиве Firebase-конфигурация заменена явной заглушкой.

## Состав передачи

ZIP содержит актуальные web/, app/, спеки/ADR/требования, lock-файлы, примеры окружения, тесты и TESTING.md. Проверяются обязательные файлы, запрещённые пути, совпадения с длинными приватными значениями локального .env и маркеры приватных ключей. Рядом создаются SHA-256 и полный список файлов.

Исключены рабочие .env, история Git, зависимости, сборки, логи, дампы, пользовательские загрузки, ключи подписи, Firebase-конфигурация владельца, устаревшие прототипы и app/supabase. Последняя папка содержала маркер приватного ключа и не вошла в пакет. Проверка содержимого не является полноценным аудитом всех секретов или безопасности кода.

APK предоставляется отдельно: debug, localhost:3000, push отключён. Исходный ZIP остаётся небольшим; для APK нужен сервер из этого же пакета и настройка подключения по инструкции.
