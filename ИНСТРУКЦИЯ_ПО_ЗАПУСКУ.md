# 🚀 Инструкция по запуску Fixly для напарника / одногруппника

Привет! Это полный исходный код проекта **Fixly** (Монорепозиторий: Веб-платформа Next.js + Мобильное приложение Flutter + База данных PostgreSQL).

---

## ⚡ Быстрый старт в 1 клик (Windows)
В корне архива есть готовый файл:
👉 **`START_FIXLY.bat`** (просто дважды кликни по нему, и он сам все настроит и предложит запустить сайт или приложение).

---

## 💻 Вариант 1: Запуск Веб-платформы (Кабинет председателя + Жильцы PWA)

### Необходимый софт:
- **Node.js** (версия 20 или 22 LTS) — [скачать с nodejs.org](https://nodejs.org/)
- *(Опционально)* **Docker Desktop** — если нужна локальная база данных.

### Команды в терминале:
1. Открой терминал в папке проекта:
   ```bash
   cd web
   ```
2. Установи зависимости:
   ```bash
   npm install
   ```
3. Сгенерируй Prisma-клиент:
   ```bash
   npx prisma generate
   ```
4. Запусти dev-сервер:
   ```bash
   npm run dev
   ```
5. Открой в браузере: **`http://localhost:3000`**

> **Примечание по базе данных:**  
> Если установлен Docker, базу можно поднять одной командой из корня:  
> `docker compose up -d postgres pgbouncer`  
> Либо в `web/.env` можно указать ссылку на любую облачную БД Postgres (Supabase, Neon и т.д.).

## 📱 Вариант 2: Запуск Мобильного приложения (Flutter)

### Необходимый софт:
- **Flutter SDK** (3.3+) — [flutter.dev](https://flutter.dev/)
- Chrome (для быстрого теста) либо Android Studio / эмулятор телефона.

### Команды в терминале:
1. Перейди в папку приложения:
   ```bash
   cd app
   ```
2. Подтяни зависимости:
   ```bash
   flutter pub get
   ```
3. Запусти в браузере Chrome (без установки тяжелого эмулятора):
   ```bash
   flutter run -d chrome
   ```
   *Либо для запуска на телефоне/эмуляторе:*
   ```bash
   flutter run
   ```

## 📂 Структура проекта
* **`web/`** — Сайт и PWA (Next.js 15, React 19, Tailwind CSS, Prisma ORM, Server Actions).
* **`app/`** — Кроссплатформенное мобильное приложение (Flutter, Dart, Provider, Secure Storage).
* **`prisma/`** — Схема базы данных, модели ОСИ, квартир, голосований и отчетов.
* **`docs/`** — Архитектурные требования, спецификации модулей и Приказа №163.
